## ▶️ How to Compile and Run a Java Program

Make sure Java JDK is installed and available in your terminal.

### Example: Running a program inside a package

Suppose the file is located at `src/Search/Linear.java` and starts with:

```java
package Search;
```

**Step 1: Open the terminal in the `src` directory.**

```powershell
cd D:\Java\practice\src
```

**Step 2: Compile the Java file.**

```powershell
javac Search\Linear.java
```

**Step 3: Run the program.**

```powershell
java Search.Linear
```

> **Important:** Use the fully qualified class name when running a class inside a package. Do not add `.java` or `.class` to the run command.

### Running a Java file without a package

If a file named `App.java` is directly inside the current directory and has no `package` declaration:

```bash
javac App.java
java App
```
